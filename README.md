#  Mobile Sales Analytics Dashboard

## Overview
Analysed ₹769M in sales across 3,835 transactions — visualising brand performance, 
city trends, payment splits, and day-level ATV with dynamic DAX measures.

## Tech Stack
- Power BI & DAX
- Tableau
- Excel / CSV Data

## Key Insights
- Tracked sales across multiple cities and brands
- Built dynamic DAX measures for Average Transaction Value (ATV)
- Visualised payment method splits and daily trends
